Lighter 永續合約平台發生 API 金鑰外洩事件，兩家做市商帳戶損失約 1550 萬美元 USDC，攻擊者利用重複 nonce 推算私鑰，再透過公共流動性池間接轉移資金。平台表示智能合約與協議本身未受影響，已透過 Guardian 機制暫停提領並追回約 500 萬美元。DefiLlama 記錄 11-16 事件損失 1039 萬美元，手法為 API Key Compromised。對 LP 與做市機器人而言，重點在於 API 權限邊界與簽名實作風險，而非合約漏洞。

  • Lighter Perps API 金鑰外洩事件，攻擊者利用重複 nonce 從公開簽名推算私鑰，透過受害帳戶建立 0 費公共池並轉移資金，損失約 1550 萬美元 USDC（DefiLlama 記錄 1039 萬）。平台合約未受影響，已追回部分資金並恢復提領。 ▸若跑做市機器人或 LP 策略使用 API 金鑰，需改用官方 SDK 避免 nonce 重複；公共池轉帳機制可能被利用繞過提領限制，建議檢查 API 權限與 IP 白名單設定。緊急提領暫停風險會影響資金流動性。
  • DefiLlama 記錄其他近期安全事件：Gonka AI Bridge Logic Flaw 105 萬美元、RNT Lend Private Key Compromised 95 萬美元、K3 Capital Incorrect Share Accounting 342 萬美元。 ▸暫無直接影響 Lighter 以外協議，但 Private Key 與 Share Accounting 手法值得注意是否適用自家 LP 策略。
