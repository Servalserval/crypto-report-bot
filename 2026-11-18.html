多起 DeFi 駭客事件 LP 資金安全受關注

11 月 16-17 日連續發生 Lighter、Safe 多簽、MORE Markets 及 B18TimeBank 等安全事件，損失合計逾 1800 萬美元，主要涉及 API 金鑰外洩、模組金鑰遭駭與閃貸攻擊。協議智能合約多數未受影響，但 LP 與做市商帳戶層級損失凸顯第三方工具與簽名機制風險。這些事件直接影響實際在鏈上跑 LP 與永續做市策略者的資金安全與操作流程。

  • Lighter 永續 DEX API 金鑰外洩，損失約 1039-1550 萬 USDC ▸做市機器人與 LP 需立即審查非官方 SDK nonce 重複使用與 API 金鑰管理，避免帳戶層級資金被提領；平台已恢復但仍應監控提幣。
  • Safe 多簽錢包 Zodiac Roles 金鑰外洩，損失約 645 萬美元 ▸常見於 DeFi LP 與協議金庫的 Safe 多簽需加強角色權限與第三方模組金鑰管理，降低模組漏洞風險。
  • MORE Markets 閃貸自清算漏洞，損失 30.8 萬美元 ▸借貸協議 LP 需關注 e-mode 倉位與清算邏輯，跨鏈複雜機制可能放大風險，建議監控異常清算。
  • B18TimeBank Base 協議獎勵憑證漏洞，損失 40.45 萬 USDC ▸時間鎖或獎勵型協議 LP 需留意已簽署憑證贖回風險，及時監控異常提領與結算合約。
