Chainflip 驗證者簽名金鑰遭破解 損失逾 1200 萬美元

Chainflip 於 11 月 21 日發生金庫簽名金鑰洩露事件，攻擊者利用有效 Schnorr 簽名轉走約 4.86M 美元 ETH 與穩定幣及 122.86 BTC，總損失近 1200 萬美元。協議隨即進入 Safe Mode，暫停所有 swaps、存款與提款，目前提供 10% bounty 要求 23 日前歸還 90%。此事件凸顯跨鏈橋金鑰管理風險，LP 需特別注意 validator key 相關協議的安全假設。

  • Chainflip 金庫簽名金鑰洩露，攻擊者利用 aggregate validator signing key 轉走 122.86 BTC、520 ETH 及穩定幣 ▸直接影響使用 Chainflip 跨鏈 LP 的資金安全，協議處於 Safe Mode 期間無法操作倉位；其他使用類似 validator/aggregate key 機制的 ve(3,3) 或跨鏈 DEX 需審查自身金鑰輪換與多簽設定
  • DefiLlama 記錄 11-21 Chainflip AMM 4.86M 美元損失，手法 Validator Key Compromised；另有 CyberConnect Cross-Chain Message Spoofing 等事件 ▸Chainflip 事件對 LP 資金安全有直接衝擊；其他事件規模較小或手法不同，暫無直接影響但提醒注意跨鏈訊息驗證與基礎設施金鑰保護
