Set Protocol 與 MakerDAO Keeper 發生新駭客事件

今日 DefiLlama 記錄 Set Protocol 因 rounding error 損失約 2.2 萬美元，MakerDAO ETH-A Liquidation Keeper Bot 因 improper access control 損失 53.8 萬美元。Duelbits 熱錢包事件雖列為 10 月 6 日，但公開資訊指向 9 月 24 日舊案，疑為重複報導。這些事件重點在特定合約邏輯與權限控制漏洞，對 LP 操作者提醒需審查 keeper bot 與 fee 計算機制。

  • Set Protocol 發生 rounding error 攻擊，損失約 21,873 美元 ▸攻擊者利用 actualizeFee() 向上 rounding 機制，在無 fee 情況下增加 unitShares 後贖回，提取既有持有人抵押品。LP 若使用類似 Set 產品或 fee 更新邏輯，需測試無 fee 更新是否影響可提領額度。
  • MakerDAO ETH-A Liquidation Keeper Bot 因 improper access control 損失 538,000 美元 ▸舊版 keeper bot exit 未受 ds-auth 保護，攻擊者直接提取 200 WETH。跑 LP 策略者若依賴類似 liquidation keeper，需確認所有 exit 路徑都有適當權限控制。
  • Duelbits 熱錢包疑似私鑰妥協，損失約 607 萬美元 ▸CEX 熱錢包事件可能影響相關資產流動性與對手方暴露，但 Duelbits 非 DeFi LP 直接協議，暫無直接影響。持續關注是否波及 DeFi 橋或穩定幣流動性。
檢查自家 LP 策略是否使用 Set Protocol 類產品或 keeper bot，驗證 fee 更新與 exit 權限控制。✅ 該做的事
